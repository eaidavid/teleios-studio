# Guia de análise · Agência Teleios

Avalie como um consultor que vai ligar para o dono amanhã.
- Oportunidade (0–100): quanto a Teleios pode gerar de resultado aqui (agenda, orçamento, venda), não "quão ruim é o digital".
- Lacunas: no máximo 4, cada uma com o efeito no negócio ("quem busca 'planejados Anápolis' não encontra vocês").
- Ângulo: o gancho mais forte e verdadeiro para a primeira conversa.
- Use só dados reais do lead. Se algo não foi verificado, diga que não foi verificado.
